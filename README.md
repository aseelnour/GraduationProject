## 📌 Overview

**GiveHope** is a full-stack charity platform designed to connect people in need with donors and charitable organizations through a secure and organized digital environment.

The platform aims to make charitable assistance more accessible, transparent, and efficient by providing a centralized system for submitting assistance requests, reviewing applications, managing donations, and communicating with beneficiaries.

GiveHope focuses on protecting the privacy of people requesting help while supporting a structured verification and approval process.

## ✨ Key Features

- **User Authentication:** Secure registration and login using JWT authentication.
- **Role-Based Access Control:** Different permissions and dashboards based on user roles.
- **Confidential Assistance Requests:** Users can submit requests for help while maintaining their privacy.
- **Request Review & Approval:** Authorized users can review submitted requests and manage approval workflows.
- **Donation Management:** Support charitable campaigns and donation-related activities.
- **Document Management:** Upload and manage supporting documents for assistance requests.
- **Cloud Media Storage:** Upload and manage images and documents using Cloudinary.
- **Push Notifications:** Firebase Cloud Messaging (FCM) for notifications and important updates.
- **Role-Specific Dashboards:** Dedicated interfaces for managing platform activities and user workflows.

## 👥 User Roles

The platform supports different user roles, each with specific responsibilities:

| Role | Responsibilities |
|---|---|
| **Admin** | Manage platform activities, users, and assistance requests. |
| **Beneficiary** | Submit assistance requests and follow their status. |
| **Donor** | Explore donation opportunities and support people in need. |

## 🔐 Security & Privacy

GiveHope was designed with particular attention to the privacy and security of beneficiaries.

- Password hashing for secure credential storage.
- JWT-based authentication.
- Role-based authorization.
- Controlled access to confidential assistance requests.
- Secure handling of uploaded documents and media.
